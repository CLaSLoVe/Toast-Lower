## 怎么玩

| 动作 | 电脑 | 手机（横屏） |
| --- | --- | --- |
| 扶杯 | Q / W 或 ← / → | 左手摇杆左右推 |
| 调整高度 | O / P 或 ↓ / ↑ | 左手摇杆上下推 |
| 敬酒 | 空格 | 右手点「敬酒」 |
| 砸穿地板 | 砸楼回合按住 O / ↓ | 摇杆持续向下推 |
| 暂停 | Esc / 暂停按钮 | 右上角暂停按钮 |
| 返回主页 | 右上角房子图标 | 右上角房子图标 |

电脑还支持 R 重开、M 静音。首页和游戏中都可打开「设置」调音量，关闭后继续当前游戏。首页可选择难度或进入教程。手机摇杆支持斜推，松手保留惯性；画面始终横屏；即使手机锁定竖屏，游戏画面和触控也会在网页内自动旋转，无需解锁系统旋转。

倒计时红色 **0s** 对齐最佳敬酒时机。酒量归零就结束；敬酒失误罚酒，成功回合少量添酒。成功碰杯本身不耗酒。完美碰杯同时要求拍子准、杯子稳。后期杯子变小，容量也会减少。

简单保持原有手感；普通继承原高难配置；新高难进一步收紧高度和拍点，并加强扶杯要求。高度范围分别为100%／65%／45%，开局杯容量为100%／80%／70%，后期最小容量均为60%。过层添酒为10%／4%／4%；成功回合添酒和整组罚酒规则不变。高难单次拍点容错从前期±0.15秒收紧到后期±0.12秒，连拍为0.20拍；外星仍是2秒倒计时、最后1秒揭晓。

## 四章十二关

| 章节 | 挑战 |
| --- | --- |
| 职场 | 调整高度，学会单次敬酒 |
| 地下交通 | 在晃动中扶稳杯子 |
| 古墓 | 固定高度，连续踩 2 / 3 / 4 拍 |
| 外星人 | 三杯同步倒计时 2 秒，最后 1 秒只保留目标圆圈并出现辅助线，0 秒才上前碰杯；允许连续选中同一位 |

十二关结束先结算。漫画成绩单保留称号、分数、难度、完美与失误次数、最高连敬，默认只展示三项得分；点「查看明细」可看酒量账本。可选择「继续无尽」或「返回主页」。音乐持续衔接到无尽。

十二关满分100,000分，三种难度使用相同分制：

| 项目 | 最高分 | 规则 |
| --- | ---: | --- |
| 敬酒表现 | 40,000 | 每章10,000，分到各关、各组和各拍；首次普通成功得50%，完美得100%，失误得0 |
| 过关与通关 | 50,000 | 每关3,000，十二关通关另奖14,000 |
| 保酒奖励 | 10,000 | 结算剩酒最多5,000，满杯兑换最多5,000 |

每拍只有首次尝试计分。补敬能推进，但不补回失误分、不重复积累气势或兑换满杯奖励；连击和气势保留反馈，不再单独加分。通关至少获得50,000分；首次全普通成功为70,000～80,000分，首次全完美为90,000～100,000分。称号仍只按分数判定。

剩酒按当前杯子的装满比例结算一次，继续无尽不重复发放。首次计分回合和首次过层添酒时，装不下的部分每1%兑换50分，全局最多5,000分；实际加进杯子的酒只记入添酒，不兑换。酒量账为：开局＋实际添酒−洒酒−罚酒−换杯减少＝剩酒。结算失败时直接提示最后一次扣空酒的原因。

最高分跨难度共用并标注难度；自定义参数、练习手感、跳关和自动操作不覆盖标准纪录。无尽可继续积累表现分和过层分，不受十二关的100,000分上限约束；通关与剩酒奖励不重复发放，满杯兑换仍共享原上限。本版采用新计分纪录，旧纪录保留在本机存储中。

连环敬酒的累计罚酒：两连为12%／20%，三连为12%／16%／20%，四连为12%／16%／18%／20%。一组至少碰上一次，结束后添酒一次（默认3%）；全错不添酒。只有整组连中才进入下一组；漏拍后在同一高度重敬，已尝试过的拍点不会重新给分。百分比均按标准大杯容量计算，高难开局小杯也使用同一单位，结算显示实际洒酒、罚酒和添酒总量。

```sh
python3 -m http.server 8783 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8783/>。

## 修改与检查

- `game.js`：物理、画面与游戏流程。
- `rules.js`：酒量计算、固定计分机会、碰杯得分与称号门槛。
- `chapters.js`：关卡、角色与台词。
- `input-ui.js`：键盘与触控映射、双端操作提示。
- `config.js`：带中文说明的参数默认值、范围和单位。
- `settings.js` / `settings.css`：玩家设置与独立测试面板。「设置」可即时调整音乐、音效、漏酒声、静音和首次引导，不会重开；首页或暂停时点「···」或按 Shift+D 可调测试参数，修改规则后重开。
- `music.js` / `audio-clock.js` / `assets/audio/`：声音混合与回合时钟，音乐卡住时倒计时安全切换为独立计时；`tools/make_music.py` 保留音乐合成源。
- `assets/home/`：当前主页背景、Logo 和网页图标。
- `tests/`：不使用浏览器或 GPU 的逻辑测试，覆盖范围见 [测试说明](tests/README.md)。

游戏内设置仅保存在当前浏览器。规则默认值更新后，玩家音量偏好仍保留。每种章节机制首次遇到时有极短提示，可在设置中关闭；修改 `config.js` 可调整发布版本的默认参数。无需安装 npm 依赖，使用 Node.js 22 或更新版本：

```sh
npm test
npm run build
```
