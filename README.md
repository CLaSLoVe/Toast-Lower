# 敬酒模拟器 · Toast Lower

**[点这里开席！](https://claslove.github.io/Toast-Lower/)**

扶稳酒杯、调整高度，听准第三声提示音碰杯。原生 JavaScript / Canvas 2D 小游戏，支持电脑和手机，无需安装。

## 怎么玩

| 动作 | 电脑 | 手机（横屏） |
| --- | --- | --- |
| 扶杯 | Q / W 或 ← / → | 左手摇杆左右推 |
| 调整高度 | O / P 或 ↓ / ↑ | 左手摇杆上下推 |
| 敬酒 | 空格 | 右手点「敬酒」 |
| 砸穿地板 | 砸楼回合按住 O / ↓ | 摇杆持续向下推 |
| 暂停 | Esc / 暂停按钮 | 右上角暂停按钮 |
| 返回主页 | 右上角「主页」 | 右上角「主页」 |

电脑还支持 R 重开、M 静音。首页可选择难度或进入教程。手机摇杆支持斜推，松手保留惯性；旋转回竖屏会暂停。

倒计时红色 **0s** 对齐最佳敬酒时机。酒洒光就结束；敬酒失败扣酒，回合结束少量补酒。完美碰杯同时要求拍子准、杯子稳。后期杯子变小，容量也会减少。

## 四章十二关

| 章节 | 挑战 |
| --- | --- |
| 职场 | 调整高度，学会单次敬酒 |
| 地下交通 | 在晃动中扶稳杯子 |
| 古墓 | 固定高度，连续踩 2 / 3 / 4 拍 |
| 外星人 | 三杯同时倒计时，最后两拍辨认并追到真目标 |

十二关后可继续无尽模式。三档难度：我爸是局长、00后整顿酒桌、35岁，杯杯是房贷。

## 本地运行

在项目目录运行：

```sh
python3 -m http.server 8783 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8783/>。音乐会在点击开始后播放。

## 修改与检查

- `game.js`：画面、物理、关卡和操作。
- `config.js`：带中文说明的参数默认值、范围和单位。
- `settings.js` / `settings.css`：隐藏调试设置。首页或暂停时点击「···」，也可按 Shift+D。
- `music.js` / `assets/audio/`：音乐播放与节拍时钟；`tools/make_music.py` 保留音乐合成源。
- `assets/home/`：当前主页背景、Logo 和网页图标。
- `tests/`：不使用浏览器或 GPU 的逻辑测试，覆盖范围见 [测试说明](tests/README.md)。

游戏内设置仅保存在当前浏览器；修改 `config.js` 可调整发布版本的默认参数。无需安装 npm 依赖，使用 Node.js 22 或更新版本：

```sh
npm test
npm run build
```

完整模拟回归可运行 `npm run test:full`。构建产物在 `dist/`，仅包含运行游戏必需的文件，资源路径兼容 GitHub Pages 项目子目录。

## 发布

GitHub Pages 使用 GitHub Actions。推送到 `main` 后自动运行测试、构建并发布；拉取请求只检查，不部署。部署进度见仓库的 **Actions** 页面。

录屏、截图、旧版本、旧图片和本机临时文件不会上传，测试与开发工具也不会进入网页发布包。
